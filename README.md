# coursework_project
# Модуль для работы с геометрическими фигурами(полный код на Python и файлы)
Инструкция к работе с модулем:
1. Создать папку на рабочем столе (название на усмотрение пользователя)
2. Скачать .zip файлы и файл .py
3. Распоковать папки .zip
4. В ранее созданую папку поместить все распакованые файлы и файл .py
5. В адресной строке папки пишем cmd и откроется консольное окно, в нем пишем команду python test2.py
6. После данных действий откроется модуль и можно в нем работать

Что делать если нет Python:
1. Переходим по ссылке на официальный сайт Python: python.org
2. Захона раздел Downloads, нажимаем на желтую кнопку с актуальной версией (например, Download Python 3.12.x или новее)
3. Запустите скачанный файл (обычно имеет имя вроде python-3.x.x-amd64.exe)
4. В самом нижнем ряду открывшегося окна поставьте галочку напротив «Add python.exe to PATH» (Добавить Python в PATH). Без этого команды не будут работать в консоли
5. Нажмите на кнопку Install Now (Установить сейчас) вверху
6. Дождитесь окончания установки и нажмите Close
7. После скачивания открыть любую папку, кликните по адресной строке, ввести туда cmd
8. В открывшейся консоли ввести python --version
9. Если на экране появилась версия программы (например, Python 3.12.0), установка прошла успешно

В модуле используется библиотека PyQt5, ее так же надо установить:
1. В консоли где проверялась версия Pythona ввести команду pip install PyQt5
2. Дождитесь окончания загрузки (появится надпись Successfully installed)
3. Так же требуется дополнительно установить tools, для этого в той же консоли пишется команда pip install pyqt5-tools
